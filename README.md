# Text Summarizer

A simple text summarization tool using Natural Language Processing (NLP) with NLTK. This project takes an article or text as input and generates a summary by extracting the most important sentences.

## Features:
- Tokenizes text into sentences and words
- Removes stopwords
- Scores sentences based on word frequency
- Outputs a concise summary

## Requirements:
- Python 3.x
- nltk library
